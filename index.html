    How it works

    Markdown on the left. Slides on the right.

    Everyone types in the same slides.md, at the same time. Slidev renders each keystroke next to it. Slidango AI drafts a speaker note when you ask, and it shows up like anyone else's edit.

    Write in Markdown

    --- layout: two-cols --- # Get started - Run docker compose up - Invite your team

    Plain text in, Slidev slides out. Diff it, review it, keep it in Git next to your code.

    Edit together, live

    # Agendamelanie - Live demoharry - Self-hosting in five minutesgabriel - Q&AAI

    Four cursors, one slides.md. No locked files, no copies by email. Yjs keeps everyone in step.

    An AI that takes turns

    > shorten slide 3 to three bullets ~ slide 3: 5 → 3 bullets [Tab] accept [Esc] discard

    It proposes, you decide. Every change is a visible diff. It runs on the model you choose, OpenAI-compatible or local. Connect Claude, Cursor or any MCP client: its edits show up as diffs, like everyone else's.

    It takes two to tango. Slidango takes your whole team … and your agent.

    Self-host

    Your server. Your decks.

    One docker compose up on any server with Docker. Caddy handles HTTPS. No account, no SaaS, MIT-licensed.

    • Decks are plain slides.md files on your disk.
    • Login via password or your own SSO (OIDC).
    • Bring your own Slidev theme, every deck follows it.
    terminal 
    $ git clone https://github.com/slidango/slidango
$ cd slidango && cp .env.example .env
  # set APP_DOMAIN, PREVIEW_DOMAIN and a login
$ docker compose up -d
  ✔ caddy  ✔ app  started
  → https://slides.example.com
    GL
    “Collaboration, code or AI? I wanted all three.”

    Collaborative slide apps let a team work together, but the deck is a black box. Slidev gives you code, but only one person types. Slidango is slides in Markdown that several people write at once. Plain text is also the one format an AI can really read and write. That is why Slidango AI can join in: it edits the same file as everyone else, with diffs you can check. It is a private open-source project, built on Slidev.
